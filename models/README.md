# Models

This directory holds the trained model artefacts used by EXAI-ResumeIntel.

**Author:** Mithin Sagar S ([@mithinsagar](https://github.com/mithinsagar))

## Contents

```
models/
├── embedding_engine.pkl        Custom TF-IDF + SVD engine (research pipeline)
├── job_df.pkl                  Pandas DataFrame of job postings (Streamlit app)
└── job_embeddings.memmap       Precomputed SBERT embeddings (Streamlit app)
```

All model files are gitignored due to their size &mdash; download them from Hugging Face Hub.

## Getting the models

**Automated download:**
```bash
bash scripts/download_data.sh
```

**Manual download:**
```bash
huggingface-cli download mithinsagar/exai-resumeintel-models \
  --repo-type model --local-dir models
```

**Or via the web interface:**
[huggingface.co/mithinsagar/exai-resumeintel-models](https://huggingface.co/mithinsagar/exai-resumeintel-models)

## `embedding_engine.pkl`

**Size:** approximately 5-50 MB

Serialised `SemanticEmbeddingEngine` containing:
- Fitted `TFIDFVectorizer` (10,000 vocab, 1-3 grams, sublinear TF)
- Fitted `TruncatedSVD` (150 components, 7 power iterations)
- Corpus embedding matrix (2,484 x 150)
- Corpus labels

Generated by:
```bash
python -m training.train
```

Used by the research pipeline (`core/scorer.py`) via the FastAPI backend.

## `job_df.pkl`

**Size:** approximately 50-200 MB

Pickled Pandas DataFrame containing the job postings (Dataset 2) with the `Role` column indexed for fast role lookup.

Used by the Streamlit application (`app/backend/model_loader.py`).

## `job_embeddings.memmap`

**Size:** approximately 3-4 GB (varies with SBERT model dimensionality)

NumPy memmapped `float32` array of shape `(n_jobs, 768)` &mdash; the precomputed SBERT embeddings for every job posting.

Generated once from the `all-mpnet-base-v2` model (768-dim). Loaded lazily via `np.memmap` so it doesn't consume RAM until specific rows are accessed.

Used by the Streamlit application for chunked cosine similarity search across the full job corpus.

## Regenerating models

If the pretrained artefacts are unavailable:

```bash
# Trains embedding_engine.pkl from raw resume corpus
python -m training.train

# job_df.pkl and job_embeddings.memmap require the full jobs dataset
# and a SBERT model to precompute embeddings. See notebooks/
# for the reference procedure.
```

## Loading models in code

```python
from core.embeddings import SemanticEmbeddingEngine
engine = SemanticEmbeddingEngine.load("models/embedding_engine.pkl")

from app.backend.model_loader import load_job_data, load_sbert_model
job_df, job_embeddings = load_job_data()
sbert = load_sbert_model()
```
